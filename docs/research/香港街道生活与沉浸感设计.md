# 香港街道生活与沉浸感设计

2026-11-01 · 策划 v0.4 沿用的街道生活内容基准 · 数据盘点、场景设计与制作验收；不是已制作内容清单。

HD-2D 适配：保留本篇资产、活动和街区差异，将站口、卸货、队列、社交与声源绑定到 3D 世界位置及楼层。近景车辆、远处服务门与高差通道应呈现完整活动过程；景深不得把全部生活糊成背景。活动地理证据与艺术安排仍分开，详见 [HD-2D 空间与技术方案](HD-2D空间与技术方案.md)。

## 1. 体验目标：让玩家感觉香港正在生活

终极目标是可自由漫游、可停留观察、具有地域与时间差异的香港。地标提供方向，普通建筑与铺面形成连续界面，交通与劳动活动解释城市怎样运作，人际活动与声景让空间有生活。无剧情、无任务仍然可以有丰富的环境叙事。

上一版把生活内容压缩成“少量循环行人”，对沉浸感目标不足。本版将街道生活列为核心系统；范围控制靠逐街段完成有因果关系的场景，而不是长期只保留空建筑和随机走动的人。

同一种细节不应全城等密度铺设。广东道的旗舰商业、弥敦道的密集入口、尖东的开放空间、油麻地的市场后勤、西九的场馆与绿地，需要不同组合。香港感也包含树荫、明亮商场、安静休憩处和整洁路段，不能全城只剩破旧招牌与霓虹。

## 4. 普通街道资产库：按用途成套制作

表中是制作类型，不是所有街段必放清单。标准构件可查旧库路政署图纸；真实安装位置、磨损和临时布置仍需照片核对。[路政署标准详图](https://www.hyd.gov.hk/en/technical_references/standard_drawings/hyd_standard_drawings/index.html)

| 资产族 | 应包含的具体内容 | 与人/环境的关系 | 优先级 |
| --- | --- | --- | --- |
| 港铁出入口 | 标志柱、站名/出口号、梯口、扶梯口、玻璃升降机、扶手、雨盖/通风口 | 分别组织出站、进站、会合；不是一个通用洞口贴图 | 样板核心 |
| 巴士/小巴站 | 按营办者区分站柱、路线板、站名、候车棚、排队区、路缘停靠位置 | 排队、车辆靠站、前门上车/下车位置按车型资料核对 | 样板核心 |
| 过街设施 | 行人灯、提示音装置、信号杆、路缘坡道、触觉铺装、护栏开口、安全岛 | 人流随信号聚集与释放，轮椅/婴儿车走合适路径 | 样板核心 |
| 路面与街道家具 | 双语路牌、黄线/路口标线、井盖、排水口、栏杆、柱桩、消防栓、街灯 | 导向、遮挡、可走宽度与材质脚步声 | 样板核心 |
| 普通大楼界面 | 窄入口、楼层目录、住宅门禁、旧瓷砖/石米、窗格、铁闸、平台、商业裙房 | 楼上铺入口与首层铺面分开，NPC 有合理进出目的地 | 样板核心 |
| 商铺生活界面 | 茶餐厅菜单/卡座窗口、烧味橱窗、饼店托盘、药房、报摊候选、兑换店、当铺招牌 | 营业/关门、等位、取餐、补货；具体分店另核实 | 样板核心 |
| 后勤与劳动 | 货车尾板、手推车、笼车、纸箱、塑料筐、货盘、服务门、临时锥桶 | 货物从车到店门，有装卸结束和撤离状态 | 样板核心 |
| 停留设施 | 长椅、矮墙、花槽边、公园亭、树池、饮水机、邮筒、公厕指示 | 坐下、会合、整理行李、短时休息 | 首街段扩充 |
| 富豪雪糕车 | 车身、售卖窗、菜单牌、雪糕道具、少量排队位置 | 到场、开窗、售卖、队列消散、离开；营业地点需验证 | 高辨识活动 |
| 气候与设备 | 冷气机、排水管、雨篷、招牌背架、卷闸、地面局部水迹 | 滴水、避雨、通风机声、开关门；不是全部长期漏水 | 首街段扩充 |
| 保洁与维护 | 垃圾桶、回收容器、清洁车、扫帚、收拢纸皮、维修围挡 | 清扫/清运有前后状态；不以满地垃圾代表香港 | 后续活动 |
| 施工界面 | 按选定年代与现场核实的棚架、保护网、围板、绕行提示 | 行人路径随围挡调整；竹棚/金属棚不凭旧印象统一决定 | 有证据再放 |
| 市场专用 | 果筐、鱼袋/鱼缸、花桶、挂衣架、帆布顶、灯串、收摊推车 | 对应果栏、金鱼街、花墟、夜市等不同生产流程 | 对应街区 |
| 海滨/公园 | 海滨栏杆、救生设施、码头系泊物、树荫、长椅、草地与落叶 | 摄影、跑步、坐看海、渡轮人流；鸟类等少量环境动作 | 对应街区 |
| 酒店/商场界面 | 门廊、雨棚、行李车、落客位、保安/礼宾活动、自动门 | 的士到达、旅客卸行李、服务人员引导 | 对应街区 |

同一资产族保留现代/旧式、营业/收起、干/湿等必要变体，并控制重复频率。城市视觉的年代感先选参考时期，再处理旧设施留存，不能默认所有历史照片元素仍在现场。

## 5. 人群与微活动：让动作有起点和终点

将“行人”拆为通勤者、居民、学生、游客、店员、送货/清洁工作人员、休息日朋友群体等行为角色。角色不是按外貌绑定职业；同一人物也可在不同场景购物、等车、聊天或休息。动作、道具、速度、目的地和同行关系，比增加随机衣服颜色更有价值。

以下时间条件是设计方案，不是由 GIS 导出的真实日程。具体点位和时段需要街段调查，首版用可切换场景预设验证，之后再接入一致的城市时钟。

| 活动 | 有因果关系的动作链 | 空间/条件 | 完成标准 |
| --- | --- | --- | --- |
| 出站与换乘 | 从真实入口出现 → 找方向 → 过街/走向站牌 | 站口与人行网；通勤/休闲预设不同 | 不从墙里出现，不在出口中心永久站住 |
| 等灯与过街 | 到路缘 → 等待 → 信号允许后成组通过 | crossing 与信号控制区 | 车流、人流、提示音使用同一状态 |
| 候车与上下车 | 入队 → 车辆停稳 → 下客/上客 → 队列缩短 | 站牌、停车锚点、车门锚点 | 站牌不漂在车道上，车辆不穿过候车者 |
| 雪糕售卖 | 看菜单/排队 → 窗口停留 → 拿雪糕 → 离开 | 核实的候选驻点；非全天同位营业 | 车、人、道具同步，队伍有消散状态 |
| 货车卸货 | 停靠 → 开尾板/取货 → 推车到服务门 → 空车返回 → 收车离开 | 后勤口、可走路线、可用装卸空间 | 不是一个人永远原地举箱子 |
| 商铺补货 | 接货 → 搬入门内/摆到货架 → 收空箱 | 合适商铺与时段 | 货物数量/位置有简化但一致的变化 |
| 开门/收铺 | 升卷闸 → 摆牌/货架；收回 → 落闸/熄灯 | 商铺营业预设 | 关门后不再持续生成顾客 |
| 餐饮等位/外卖 | 看菜单 → 排队/等候 → 店员递袋 → 离开 | 店外凹位，不封死通道 | 等待长度会变化，动作有错峰 |
| 休息日朋友聚会 | 相约到达 → 铺坐垫/整理食物 → 交谈、分享食物、看手机 → 收拾离开 | 合适公共空间；休息日、天气允许 | 小群体关系可辨，坐姿/动作错开，留通道 |
| 游客与行李 | 拖行李 → 查地图/停看 → 同行者会合 → 继续走 | 码头、酒店、车站、商业街 | 停留点与快速通行区分开 |
| 拍照与观景 | 找视角 → 举手机/同伴站位 → 查看照片 → 离开 | 海滨和地标前 | 有方向与目标，不朝墙统一拍照 |
| 居民日常 | 购物袋/买菜车、接送小孩、长椅休息、遛狗候选 | 住宅/公园/街市相应区域 | 速度和路径不同，不全按游客逻辑行动 |
| 清洁维护 | 推车到位 → 扫/收/更换 → 收好工具 → 移往下一点 | 真实服务可达区域，活动结束后环境变化 | 与营业人流相容，不永久表演 |
| 市场收放摊 | 运入货物 → 展开摊面 → 交易 → 折叠/搬离 | 对应市场与营业预设 | 白天/夜晚不是只改天空颜色 |
| 雨天应对 | 取伞 → 路线向雨篷偏移 → 门口收伞 → 恢复行走 | 可达遮雨点、可通行宽度 | 不全员同时变装；雨停后行为逐步恢复 |
| 码头到站人流 | 船靠岸/开口 → 一批下船人流 → 分散到站口/海滨 → 平静 | 码头外围，不要求首版可乘船 | 形成有间隔的人流波，而非永远满场 |

你举的“聚集的菲佣”应具体化为**菲律宾籍家务工作者等休息日朋友群体的生活场景**：聊天、分享食物、看手机、拍照、整理物品，也包括抵达与散去。香港浸会大学的实地报道记录了这类周日活动，并提到尖沙咀、旺角及海旁；但主要照片/采访在中环，不能把报道中的中环点位搬到尖沙咀，也不能据此指定当前某个出口周周都有固定人群。[实地报道](https://lionrocktales.hkbu.edu.hk/index.php/2022/01/19/we-should-be-seen-as-citizens-not-as-slaves/)

富豪雪糕是高辨识度流动活动。旅发局资料提及天星码头、尖沙咀海滨等常见区域；这足以支持候选场景，不能把它当作固定营业坐标或全城随处必遇的密度。[旅发局雪糕车介绍](https://www.discoverhongkong.com/eng/food-and-drink/hong-kongs-essential-desserts-to-beat-the-heat.html)

果栏则更适合突出搬运、货筐和夜间/清晨工作的节奏。旅发局资料支持其凌晨经营特点；具体货车到达时间、车辆数量与工人路线仍属待调查内容。[果栏资料](https://www.discoverhongkong.com/eng/place-to-go/travel.guide-yau-ma-tei-fruit-market.html)

## 6. 声音、时间和天气也是内容

声音必须来自画面中合理的声源，并随距离、遮挡和活动状态变化。不要用一条大声“香港街头混音”覆盖全部街区。

| 声音层 | 内容候选 | 对应变化 |
| --- | --- | --- |
| 交通近声 | 行人过街提示、巴士靠站/开门、推车轮、行李轮、的士车门 | 与信号、车辆和动作同步 |
| 商业近声 | 卷闸、装卸箱筐、外卖递袋、门口碎片化交谈、厨房/通风声 | 营业时出现，绕到后巷发生变化 |
| 活动声 | 雪糕车提示旋律、朋友聊天、摄影倒数、孩子嬉闹 | 有实际声源、合适音量与间隔；不全街重复同一录音 |
| 空间底声 | 主路车流、公园叶响与鸟声、海风、远处船声、空调设备 | 街角/公园门/海滨之间可听到过渡 |
| 天气声 | 伞面雨声、雨篷滴水、车辆经过湿路 | 随雨量和表面类型变化，雨后逐渐减弱 |

过街提示音不是任意节拍：运输署资料说明其与信号状态相关，且已有分代更新。样板应先保证视听状态一致，再按选定街口核实设备年代。[运输署电子行人过路发声装置](https://www.td.gov.hk/en/transport_in_hong_kong/pedestrians/pedestrian_crossing_facilities/electronic_audible_traffic_signal/index.html)

现有库没有可直接投入游戏的录音包。官方网页用于理解现象，最终声效另行制作/取得可用素材；文字招牌、旋律、方言声景各有独立制作工作量。

首批建议提供工作日下午、休息日下午、傍晚营业、雨天四个调试预设。用户实际游玩可以先固定一个时段；多预设用于验证差异，后续才发展连续时钟。季节/天气不能只靠调色：人流、伞、反光、雨篷下停留和远景能见度需相互一致。

## 7. 用街段场景组合控制制作规模

| 场景组合 | 核心组合 | 应给玩家的体验 |
| --- | --- | --- |
| 站口商业街 | 真实站口 + 过街点 + 餐饮/便利店 + 出站/等灯/取餐 | 玩家停一会儿能看懂人从哪里来、往哪里去 |
| 广东道商铺与后勤侧街 | 商业立面 + 服务门 + 装卸位置 + 推车/收货 | 正面消费界面与侧面劳动活动相连 |
| 天星码头/海滨 | 码头 + 站牌 + 波状人流 + 观景 + 雪糕车候选 | 交通抵达、休闲停留和海港方向成立 |
| 公园边缘/休息日 | 树荫 + 长椅/可坐边缘 + 会合 + 小群体聚餐 | 从主路快节奏进入可停留的公共空间 |
| 佐敦餐饮生活街 | 密集铺面 + 住宅门口 + 等位/外卖 + 收铺 | 商业营业与居民回家并行 |
| 油麻地市场后勤 | 低层街屋 + 货筐/推车 + 装卸 + 整理摊位 | 货品、劳动动作与场所一致 |
| 旺角专门店街 | 不同货品模块 + 看货/交易 + 补货/收摊 | 金鱼街、花墟和服装摊不只靠标题区别 |
| 西九文化休闲 | 场馆前场 + 绿地 + 观展散场/跑步/坐看海 | 开放空间与密集商业街形成反差 |

这些是可复用场景规则，不是将不同真实地点拼成同一街角。当前广东道—海防道候选街角未必恰好包含 Apple、站口、雪糕车和卸货位；要根据真实邻接选择首段，必要时分别验证两个小场景。内容覆盖不靠搬动地标实现。

## 8. 让这些内容可制作、可维护

静态资产继续分层，新增一层“活动配置”：位置锚点、可走路径、停留区、道具、角色槽位、时间条件、天气条件、声源和退出条件。一个卸货事件是一组同步对象，而不是几段独立循环动画。

每个活动实例记录 `place_id、source_ids、evidence_status、anchor_ids、level_id、time_profile、weather_profile、participants、props、state、audio_zones`。证据状态分为地图快照、照片/视频观察、官方文字、设计编排、待核实；设计数据不反写地理来源。

技术建议：近景用少量可观察的状态机与路径，远景简化，离开区域保存必要活动阶段或按确定种子重建。队列/坐席/卸货位有占用管理，留通道；人物、货车、车门和道具的转换由同一活动状态驱动。地铁/码头不进入的内部可作为明确的生成/退出边界。首版不需要每人常驻全城、复杂经济系统或联网大模型对话。

城市生活是核心内容，但不意味着一次实现全部行为。第一阶段先完成“有目的地的步行、等灯/候车、卸货”中的相邻可行组合，并制作一种停留行为；第二阶段加入休息日群体与雪糕车；之后随对应街区扩展市场、海滨、酒店等活动。框架能提供的移动/触发等继续复用，活动协调、证据管理和香港特定资产由项目实现。

## 9. 验收标准改成沉浸感，而非地标数量

1. 隐去地名和品牌文字，仍可从站口、道路家具、铺面尺度、车辆、人流与声景辨认香港；再检查能否区分海滨、商业主街、生活内街等区域。
2. 在同一街角停留两分钟，至少能观察一组完整活动的开始、过程与结束；数字是样板设计目标，不是现实频率指标。
3. 行人有明确入口、出口与停留点；出站、等灯、候车的人不是同一批无目的随机巡游者。
4. 装卸时可追踪货物从车到店门；收货后角色、车辆和道具状态一致，玩家能顺畅绕行。
5. 工作日与休息日、干燥与下雨至少有行为或空间使用差异，不能仅替换人物颜色、背景音乐与天空色。
6. 群体行为存在成员间联系、错开的动作与抵达/散去；不以民族外貌替代行为设计，不把所有人群都画成同一个聚集模板。
7. 街区内容能追溯到证据或标为设计编排；流动商贩没有假装固定门牌，历史活动没有伪装为当前实测日程。
8. 视觉细节不遮住主角脚底和出口；活动占用不会堵死通道；画面模糊、灯光与音效不会掩盖玩法信息。
9. 在独立 Player 比较空街、正常活动和繁忙预设的帧时/内存；超预算优先简化远处行为，不把全部生活内容删除。
10. 请熟悉香港的人走一段并指出“哪里不像、缺了什么、哪里过度”；修改空间与行为，而不只继续追加地标。

最终验收句：**“就算没有任务，我也愿意沿街走下去，或者站在路边看一会儿。”**
