# 香港街道标识与设施：来源及制作缺口

复核日期：2026-11-01。此页是静态证据索引；实际制作使用 [WF-PROPS](../../workflows/20-assets/scenery-production.md)。通用设施标准不能证明广东道某处实际设有该设施。

## 街名牌与道路交通牌需分开

[路政署标准图第 6 节](https://www.hyd.gov.hk/en/technical_references/standard_drawings/hyd_standard_drawings/section6.html) 列出 H6153A、H6154A，主题是带楼宇号码的街名牌在路口的布置，也列有多种候车亭和临时设施图。此轮核对的是官方目录，未据此确认目标路口的全部牌面尺寸、色值、字体文件或现场安装形式。制作时应读取对应图纸并对照目标地点近年照片。

[运输署《运输策划及设计手册》](https://www.td.gov.hk/en/publications_and_press_releases/publications/tpdm/index.html) 的第 3 卷涵盖交通标志与道路标记；[道路使用者守则的标志系统](https://www.td.gov.hk/en/road_safety/road_users_code/index/chapter_8_the_language_of_the_road/the_signing_system_/?print=1) 区分标志类别。交通牌、街名牌、旅游导向牌和商业店招不应合并成一个样式。

需要补齐的目标街段证据：街名中英文准确拼写／繁体字形、文字排列和字重、牌面背景与边框颜色、号码／箭头、比例、立柱或壁挂结构、安装方向、照片日期及具体地点。**此轮没有验证准确字体名称和色值，不能凭印象写成全港统一规范。** 当前 demo 的绿色底板＋白字是占位设计，不能作为标准来源。

## 巴士站牌既是物件也是运营信息载体

[九巴 2021-11-11 官方公告](https://www.kmb.hk/news_detail.html?id=254&year=2021) 说明部分站点可通过二维码和显示屏获取预计车程；这证明设备存在，不证明每站配置相同。[九巴 2023 年官方记录](https://www.kmb.hk/storage/en.news_detail_2023.html) 介绍 App1933 的步行到站和街景功能，可作为核对具体站位的辅助入口。

目标站仍需取得营办者／站 ID、线路方向／站序、站名、顶牌／线路牌样式、安装细节、信息面近照和候车空间。运输数据说明逻辑身份，照片说明外观；二者交叉核对后才做最终牌面。当前广东道的 BUS DEMO 是演示停靠点，未证实与实地某站一一对应。

## 资产精度与证据状态

商标已有来源，但安装尺寸与建筑组合仍可能是设计编排；街名牌和站牌尚缺最终生产版式。设施纹理应保留可靠原文、图形与排版源，生成图只做草案。具体缺口和优先级见 [广东道资产目录](../08-blocks/tst-canton-demo/scene-inventory.md)，不在本页重复维护制作待办。
