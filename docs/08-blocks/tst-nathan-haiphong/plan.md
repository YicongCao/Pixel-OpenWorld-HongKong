# 第一街区：弥敦道 × 海防道

**建议从尖沙咀 A1 出口—九龙清真寺前的弥敦道西侧人行道开始，再转入海防道。** 先打磨一段能停留、转弯和观察生活的连续街景，再扩展地图。block_id：`tst-nathan-haiphong`。本轮完成选段、数据／实景核对与三张渲染概念；尚未制作街区 Unity 场景。

## 为什么从这里起步

这不是地标数量最多的选择，却能集中验证核心体验：玻璃港铁口和进出人流、巴士站位和候车队列、清真寺／树荫／商铺的体量差异、从横向主街转入纵深支路、路缘与入口台阶的遮挡。港铁街道图及 2024—2026 实景支持这些关系，详见 [来源与观察](sources.md)。

广东道—海防道更适合下一阶段的商场立面、橱窗反射和宽路口；一开始做海港城长立面容易把精力耗在大量独有商铺。天星码头／钟楼适合海景灯光，但对普通街道生活覆盖较少。西九龙站／戏曲中心尺度大、独有建筑多、跨层复杂，适合街道制作链路稳定后接入。上述排序是制作判断，不是客观评分。

## 首段边界与动线

资料窗口约 216×188 米；实际第一可走区域收缩为弥敦道西侧约 100—120 米，以及海防道东端约 80—100 米，最终长度由灰盒核实。首个美术小样再收缩为 A1 附近 20—30 米。清真寺内部、港铁站内、公园深处和弥敦道东侧均不作为首轮可走空间。

主角路线：清真寺前候车区 → 沿人行道向南到 A1 → 绕开进出人群 → 转向西进入海防道北侧树荫人行道 → 到小样边界返回。先检验横向与纵深的衔接，不要求玩家穿越弥敦道车流。楼梯、站口和公园平台分层；进站 NPC 在指定下行边界退出，玩家不进入未制作站厅。

[地图骨架](../../../data/blocks/tst-nathan-haiphong/layout-guide.png) 和 [数据包](../../../data/blocks/tst-nathan-haiphong/README.md) 保留真实坐标；没有为画面移动地标。第一主镜头从东向西，屏幕右为北，弥敦道横向，海防道向后延伸。局部镜头跟随与过渡需实机验证；第三张纵深概念是转入支路后的镜头研究，不能据此承诺无缝转镜已实现。

## 接下来怎么扩展

1. **A1 街角技术切片**：20—30 米、小巫师、路缘／入口遮挡、一个昼景；先达到美术和脚底稳定标准。
2. **本街区步行闭环**：扩至上述 100—120 米主街＋80—100 米支路。加入一组巴士靠站／候车队列、A1 双向进出和一个商铺收货活动；雨后夜景作为同一空间的后续灯光验收，不一次性叠满系统。
3. **沿海防道向西串联**：逐段接入汉口道、乐道附近连接，再到广东道与海港城；逐段核实实际路口，不把广东道直接连到佐敦道。这一步建立“密集商铺—树荫挡墙—现代商场”的空间对比。
4. **尖沙咀南部和东部成环**：从广东道南下连接 1881、天星码头／钟楼、梳士巴利道，再向 K11 MUSEA、尖东海滨扩展；海景、对岸中银大厦轮廓只在真实视线成立的机位出现。不是把它们移到九龙街口。
5. **向西北扩展现代城区**：中港城—柯士甸道／戏曲中心—高铁西九龙站；补齐天桥、站前平台和高差，需要独立跨层验收。
6. **向北延伸日常街道**：弥敦道—佐敦—油麻地—旺角，复用已验证的公交、商铺、行人和声景模块，再加入街市、后巷及地区特有生活。

这是本轮针对街区连通的建议细化，接续 [长期 Roadmap](../../06-production/roadmap.md)，不承诺固定日历。每一步以可走和生活活动完成度解锁下一片；不先铺满整个九龙白模。

## 生活与资产优先级

首轮必需：玻璃 A1、入口栏杆和扶手、清真寺外立面局部、公交雨篷与分站牌、行道树／棕榈、铺装／渠盖／路缘／交通灯、旧楼窗格和冷气机、店招及橱窗、白帽主角和常服行人。复用模块与地标独有部分分开，见 [资产与概念检查](assets.md)。

活动优先级：站口双向人流、候车与上下客、避让通行，其后才是手推车收货、清洁、外卖取件、短暂停留聊天。人物的身份与职业不能由照片外貌推断；节假日外籍家务工作者聚会应按合适空间和有据时段另做研究，不强行放在每个路口。富豪雪糕以移动事件设计，后续补具体站点／时段证据，不在 A1 画一个永久驻点冒充现实。真实商业元素逐店核对，不能把 Apple Store、7-Eleven、麦当劳等任意塞进这个街角。

## 技术实施顺序与验收门槛

Unity 6.3 LTS＋URP 3D 已完成 [环境验证](../../04-engineering/local-development.md)。下一步使用实际街网搭灰盒，固定相机与米制局部原点；输入／镜头优先使用已装 Input System 和 Cinemachine，寻路利用 AI Navigation，站口／公交活动用明确状态机。简单墙路用 Unity 几何，独特 A1 玻璃罩、清真寺局部和巴士需要时再进 Blender。

先做角色、地面和一个店面受光／深度样板，然后拆地标、公交和植被。不能把整幅概念切层当可走场景。照明与景深在 URP 3D 中逐项验证；不要用全局模糊模拟 HD-2D。

验收沿既定路线往返：不穿墙、不从站口楼梯跌落、支路始终可读、树冠和公交不长期遮住主角、NPC 有出口和目的地、队列不堵路；观察公交与进站活动至少两分钟。最后导出独立 Player 测帧时、内存、脚底和摄像机切换。当前这些街区检查均**未执行**。
