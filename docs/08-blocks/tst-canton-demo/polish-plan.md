# 从广东道 demo 到精致 HD-2D 小场景

2026-11-01 · 基于本批独立 Player 截图和用户反馈。目标是一个在构图、素材、动画、光照与生活细节上可与《八方旅人 II》小场景进行认真比较的作品切片；不是再扩大街区，也不宣称安装像素 shader 后已接近该品质。

## 初始缺口：必须先承认哪些还没有做

当前成果解决了可走空间、固定镜头与四向主角、可切换像素渲染、昼夜景深和公交状态循环。**主要视觉内容仍是原型**：

- 街道过于规整，立面与空间节奏较疏；海防道连接被表现为简化支路，既没有完整实景尺度，也缺少街口的视觉密度。真实广东道主路、商场临街面与旧街支路本来不同，不能统一挤窄。
- Apple 是大块不透明蓝绿色墙面加框线／展示台暗示，不是真实玻璃、室内层次或完整店面还原；字样也不是精修标识。
- 周边建筑主要依赖纯色材料与重复方窗。缺少经过 UV 规划、像素美术处理的独有立面、门窗、广告、金属、污渍和装饰纹理。
- 地面材质仅为前一街区图集复用，平铺尺度和路缘细节没有统一；路面、井盖、盲道、排水槽、地砖接缝、双黄线与设施仍不完整。
- 树冠是方块轮廓，巴士是盒体加窗，行人是几何占位；静态工人和纸箱不能算“卸货活动”。缺少独立角色像素图集、自然步态、活动动画与车辆轮廓。
- 店招虽可读，但部分小字经后处理仍损失笔画；暖灯、店内光、接触阴影、颜色层次和景深尚未形成一致审美。夜景偏暗；局部过亮／过糊仍需校准。
- 背景是重复体块，没有香港高层的层叠关系；前景只有低墙／少量树，没有受控的遮挡节奏。没有声景、触发交互、存档与完整生活闭环。

这不是单纯“缺几张贴图”。空间密度、轮廓、动作、字体、受光与构图都需要一起重做，否则更高分辨率的贴图只会装饰原型体块。

## 精修范围：先做一个有头有尾的小片段

先锁定约 20–30 游戏米的展示切片作为**设计候选**，包含 2–3 个连续临街立面、一个有真实依据的转角／支路、前景遮挡、三种以上人物行为及一个可见活动。具体长度和商户先由实景与脚程确认，不反写到原始地图。

当前 demo 的 68 米保留作交互回归场。精修区放 `authored/` 与独立场景／Prefab Variant，生成脚本不覆盖。优先选 Apple 附近连贯实景或一个真实转角；如果两者距离不符合小范围，就选其中之一，不拼接成不存在的邻居。

## 工序顺序与完成门槛

### 1. 空间校准与密度重排 · P0

- [ ] 补齐同一街段连续照片、店面编号和楼层依据；把建筑边界、道路宽、人行道、出入口、实际退界与高差标到立面／平面参考板。
- [ ] 以归档 footprint 和行人网核查真实关系，明确哪些距离压缩、哪些连接保持；纠正当前“宽阔空地＋孤立积木”的演示编排。
- [ ] 建立三种密度：临街建筑连续性，雨篷／招牌／空调／栏杆形成的中尺度层叠，人在店门／站位／货物附近产生的小尺度聚集。各有依据，不能用全场随机散物替代。
- [ ] 锁定一个主机位、支路深处与两端机位；保持四向可走、出口可读，记录人物屏幕高度及重要招牌最小可读尺寸。

完成门槛：关闭 DOF、移除细贴图后，黑白体块截图仍能读出“连续香港街面、横向活动带、纵深通道”；角色全路线不被永久遮住。密集不等于不可走。

### 2. 一个完整立面样板与美术合同 · P0

- [ ] 用灰盒截图＋实景生成新的 HD-2D 原画约束图；固定投影与通道，不再用最早纯 2D 概念作为建模蓝图。
- [ ] 定调色板、角色与环境像素颗粒、边缘处理、材质反应、贴图 mip／采样策略。原生、1280 与 960 比较后选定，不能让全屏降采样吞掉繁中文字。
- [ ] 先完成一个商铺转角：正面、必要侧返、雨篷、窗台、门、独立招牌、店内浅景、灯具。重点解决近看与纵深转入时的接缝、尺度及遮挡。
- [ ] 立面和玻璃分材质；需要透视层次的店内使用有限深度空间，远处窗户可烘进纹理；避免逐个建模所有砖与无法看见的室内。

完成门槛：同一资源在白天、夜间、正面、支路角度都成立；文字不由图生图乱码承担，色彩／深度／投影一致。样板没通过前不批量铺街。

### 3. 模块化贴图与资产制作 · P1

- [ ] 墙面、窗跨、楼层带、侧墙、屋顶边缘的模块与 UV；图生图初稿后做透视校正、像素整理和拼接检查。
- [ ] 店面独有包：玻璃门／橱窗、广告、招牌、产品展示、卷闸、雨篷；品牌与地址按目标街段核实，不把 7-Eleven／麦当劳自动塞进任意空位。
- [ ] 地面包：地砖、沥青、路缘、盲道、井盖、排水、标线、磨损与合理污渍。不要每隔几米出现完全相同的大污渍。
- [ ] 街道物件：灯柱、路牌、真实站牌、栏杆、垃圾桶、消防设施、货箱、手推车、折叠围挡；用途／位置核实与设计编排分开。
- [ ] 植被包：有辨识度的树干／枝形与裁切叶簇，检查风动、深度与投影；替换方块树冠。
- [ ] 中远景包：香港高层轮廓与重复窗格模块；用低复杂度体块／卡片分层，不复制七栋同尺寸灰块。

完成门槛：统一像素密度和资产尺寸；从所有允许机位看不到缺面、纹理拉伸或重复穿帮；生成源、修改源、导出和 Unity 引用可追踪。

### 4. 角色、车辆与有目的的活动 · P1

- [ ] 重整白帽四向站姿／步行：统一比例、足底、承重与步幅；逐帧和实时慢走检查滑步。八向只在四向斜走确实不足时增加。
- [ ] 制作少量有区分的真实像素 NPC，替换几何人：步行者、候车者、提袋游客、店员／搬运者；行为身份不用简单肤色／服装刻板映射。
- [ ] 巴士制作轮廓、轮子、门、内外层窗和灯；保留 HFSM，接入真实站位与路线后才使用实际线路标识。
- [ ] 完成至少一个活动闭环：工人从车取货→推车→交付→空车返回；或排队→车门打开→分流上下车→关门离开。声音与阶段同步。
- [ ] 人流按目的地和空间容量安排，在商铺入口／街角形成停留与避让；再决定是否需要 AI Navigation。不要靠复制更多往返 NPC 证明拥挤感。

完成门槛：原地观察一分钟不会只看到同步往返；连续三轮无穿墙、堆积、重复生成、未开门上车或主角被堵死。

### 5. 灯光、景深、声音与细节整合 · P1

- [ ] 先无后处理统一日景的受光与接触阴影，再做橱窗暖光、路灯和夜景。玻璃反射、发光材质和实际照明分开处理。
- [ ] 检查主角、标识、可走地带的清晰区；DOF 不遮缺面，焦点不呼吸，树叶／栅栏／文字没有强烈像素闪烁。
- [ ] 加与活动对应的环境层：远近交通、脚步、车门、停站提示、搬运、商店背景；有距离衰减与循环交叉淡化。先解决声音来源许可。
- [ ] 克制地加风、店门、招牌或纸张微动；不能所有物件同时摆动。

完成门槛：日夜各有明确视觉中心，主角不靠永久透墙辨识；截图关闭 DOF 也成立；行走中动态采样、声音和视觉没有明显割裂。

### 5.1 最终烘焙 · P1

- [x] 静态建筑／地面 UV2、Contribute GI、Mixed Baked Indirect 与动态 Light Probes；实际生成并保存产物。
- [ ] 在最终精修贴图／灯位冻结后提高密度复烘，逐机位检查接缝、漏光、探针过渡；夜景使用匹配烘焙数据。

烘焙后必须再次执行独立 Player 动线，不能把烘焙完成直接当整场景完成。

### 6. 实机打磨与对照验收 · P0 贯穿全部阶段

- [ ] 同一分辨率并排对照《八方旅人 II》**探索**截图和本场景：角色／画面比例、前中远层、立面密度、明暗、像素颗粒；不拿战斗或演出镜头作为默认导航镜头。
- [ ] 留下主街往返、纵深进出、停步、拥挤处通过及日夜录像；看运动中的抖动、遮挡与步态，而不只选一张好看的截图。
- [ ] 目标设备跑十分钟，覆盖人流、公交、灯光和景深；记录帧时分位数、峰值、GC、内存及 draw call。现有约一分钟测试不能代替整段稳定性。
- [ ] 再按 profiler 结果合批／实例化／烘焙或简化，不提前以低分辨率掩盖成本。渲染 pass 开关做相同条件测量。
- [ ] 冻结可运行版本、资源清单与证据，再复制模块到下一个街段。

## 下一批最值得执行的交付

先完成 **空间密度重排＋一个精修立面包＋白帽动作修订＋同机位对照**。其余街段、更多品牌与交通路线延后扩展。判断是否前进的标准是这个小片段有没有可信的香港密度、清楚的探索方向和一致的像素美术，而不是增加了多少 prefab。
