## 六项可观察差距

1. **Apple 玻璃与浅室内——最大视觉收益。** 实机大面积米白表面，后墙、桌子、柱子明度接近；概念中玻璃反射、银柱、深处展示墙、右侧楼梯和两层桌面区分清楚，前后遮挡建立空间。应补可见墙／天花、侧返、楼梯轮廓、玻璃框和设备组，分离玻璃、金属、木料的材质响应；不必建不可见后勤区域。验收：DOF 关闭仍能分清玻璃前沿、桌面和后墙，左右走动没有严重透明排序错误。
2. **像素语言——当前颗粒有了，组织还不统一。** 实机铺砖很密、墙窗重复、部分道具仍是平色方块；概念的轮廓、窗台凹凸和材质色块更有层级，但部分玻璃／树叶又过于平滑。应先统一白帽、一个窗跨、一块地砖、一组店面道具的像素密度和调色板，减小噪点，以有意设计的像素簇表示边缘、磨损与明暗。验收：原生与默认像素档均成立，移动不严重闪烁，不靠降低全屏分辨率代替美术。
3. **店铺识别从标志延伸到店面类型。** 实机已有 Apple／SaSa 标识，但莎莎柜台和商品还是简化几何，后方图案不能充分表达化妆品店；概念补了分组陈列、海报区、入口凹槽和门框。优先做货架、商品簇和门框模块，文字独立制作，店面内只做可见纵深。验收：遮住商标仍能区分电子产品店与化妆品店；标志清晰但不过曝。
4. **受光与接地——已有烘焙仍需材质配合。** 实机阴影存在，但柱／桌／地板之间的对比偏弱；概念以树影、脚底接触、室内局部亮区、冷暖区分增强体积。应先检查材质与灯位，再调间接光和探针，几何稳定后重烘。验收：关闭 Bloom／DOF 仍成立，人物走过店内外明暗边界不过曝、不突然变黑。
5. **人物与生活细节——单帧只能提方向。** 实机白帽和各 NPC 的轮廓／颗粒尚不完全一致，候车人仍有几何占位；概念给出了店员、顾客、搬运货物的更明确视觉角色，但没有证明动作闭环。应替换候车占位、整理站姿与搬箱帧、保留活动锚点并加入避让。验收仍需播放和试走，不能用概念中一群人证明“更有生活”。
6. **前中远层次与景深——最后处理。** 实机有前景植物与店后空间，但暗部和虚化过渡尚粗；概念前景叶簇、活动带、室内分层更清楚。先校正几何、alpha 裁切与焦点，再轻调 DOF。验收：主角、路缘、标志和纵深入口清楚，前景不会长时间挡住可走区。无需为这幅图增加新巷子。

## 概念本身不能照搬的部分

- SaSa 霓虹过亮；现实照片为洋红标志，不意味着要全时高 Bloom。正式材质优先清晰轮廓与合理发光。
- 建筑、树叶、反射部分偏精细平滑，需再做像素簇约束；这是材质与灯光方向参考，不是已验收的最终 HD-2D 纹理标准。
- 新增的 Apple 展示墙、商品摆放、店员及文利大厦大堂细节是生成推断，不是实景测绘；大堂暂不作为真实建筑内饰实施。
- 前景植物变大、铺位宽度与部分基线发生变化，不能反写当前地图／碰撞。当前两店的压缩编排本身也未成为精确城市还原。
- 图中的字形、设备、反射与阴影不自动成为可用资产；需按分件制作并在 Unity 验证。
