# 弥敦道 × 海防道逻辑骨架

范围 CRS84 `[114.1705,22.2976,114.1726,22.2993]`，约 216×188 米的资料窗口，含背景与缓冲，不等于首版全部开放。提取自本项目已从 game-research 复制的快照；上游只读，来源链见 [manifest](manifest.json) 与 [母包](../../hong-kong/README.md)。

- 道路 70、建筑脚印 55、POI 50、轨道入口候选 5、街道节点 36；这些包含重叠和背景，不能相加为资产数量。
- 三维行人路径 234，保留 EPSG:2326 米制 XY 和 HKPD Z；关系表保留母包选区上下文，不自动连通地面／地下／公园平台。
- 运输署完整表派生：巴士站点 3、区内站序 92；小巴站点 2、区内站序 4。站序为部分线路，不是轨迹。
- 另存 2026-11-01 官方 KMB API 快照：窗口内 9 个营办者站位。其 ID 与运输署 STOP_ID 不同，不按数量直接对齐。
- 港铁街道／布局 PDF 复用同一快照，图内印刷日期 10/2025；A1 与站侧关系已目视核对。不是今日现场通行确认。

[布局引导图](layout-guide.png) 叠加真实道路／脚印和设计镜头。[design-layout.json](design-layout.json) 的镜头及虚线路线是设计草案；路线尚未按碰撞／实际边界校正。主街弥敦道在世界中南北向，相机由东向西时屏幕右侧是北；海防道向西进入画面纵深。

数据脚本 `scripts/extract_first_block.py`，制图 `scripts/build_first_block_guide.py`。使用研究 Python 环境从仓库根运行。在线 KMB 原响应仅用于首次采集，已入库的是带来源哈希、服务类型／方向／站序的子集；离线重建应保留该快照，不声称重新请求了实时数据。
