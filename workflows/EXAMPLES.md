# 工作流使用举例

以下整理自用户的两组问题及对应回答，帮助后续 Agent 从需求选择主工作流、组合子流程并确定验收边界。示例不是新增的独立 workflow，也不表示这些制作任务已经执行；具体步骤以链接的流程维护源为准。

## 示例一：精修站牌、改造观光巴士、增加出租车

**用户问题：**

> 如果我的需求是精修公交站牌、精修公交车（改为双层观光巴士）、增加出租车（还原真实红滴、绿滴、蓝滴涂装），会用到哪些 workflow？

**回答：**

这是资产精修与交通整合任务，以 [WF-PROPS 景物制作](20-assets/scenery-production.md) 为主流程。

1. **取证与明确车型**：核对站牌营办者、方向、线路及版式；确定观光巴士具体车型、涂装和是否敞篷；出租车核对车身、车顶、标识与涂装。三种出租车分别做资产，但是否投放到广东道，要另外核实运营地域与现场依据。
2. **制作资产**：站牌执行 WF-PROPS 配方 C，巴士／出租车执行配方 H。能共享的车身与材质做变体，车门、轮子、标识分别处理；不能假设所有车型只换颜色即可。
3. **调用 [WF-SCENE 装配与运行](10-hd2d/scene-assembly-validation.md)**：替换现有资产，配置车道、停靠点、车门、候车队列和上下客关系；观光巴士不能直接沿用普通公交的站位与运营逻辑而不核对。
4. **调用 [WF-LIGHT 受光验证](10-hd2d/camera-lighting.md)**：检查动态车辆的探针受光、阴影、玻璃与反射；静态站牌变化影响烘焙时重烘。动态车辆本身不烘进静态光照。
5. **按需调用 [WF-CHAR 角色制作](20-assets/character-production.md)**：只有新增司机、乘客、上下车等动作时才进入角色制作。

全程配合 [WF-ITERATE](10-hd2d/iteration-and-fidelity.md) 做固定机位前后对照；收到用户反馈，通过 [WF-MAINTAIN](00-project/workflow-maintenance.md) 更新对应配方和检查项。通常不必重跑整个街区总流程。

**给后续 Agent 的启发：**从被修改的资产类型进入流程，但验收要覆盖它在场景中的运行关系。精修站牌不仅是画牌面，换车也不仅是换模型；是否需要角色动作、重烘或重新取证，由实际影响决定。

## 示例二：按 20–30 米单位连续制作广东道

**用户问题：**

> 如果我的需求是继续实现广东道剩余的街景，以制作 20–30 米的范围为一个小单位，一个单位一个单位地推进，会用到哪些 workflow？

**回答：**

这是连续街区扩建任务，以 [WF-BLOCK 街区还原总流程](00-project/街区还原工作流.md) 为主，每个小单位完成一次闭环。

1. **选段与取证**：确定范围、真实建筑／设施、道路连接和本段验证路线，复用已有地图，仅补缺项。
2. **调用 [WF-HD2D](10-hd2d/hd2d-production-workflow.md)**：沿用已验证的镜头与像素规范，检查新段的可见面、纵深连接和下一探索目标，再生成对应概念参考。
3. **调用 [WF-BUILDING](20-assets/building-production.md)＋[WF-PROPS](20-assets/scenery-production.md)**：制作建筑、商铺、标识与景物，优先复用已有模块。新人物或动作才调用 WF-CHAR。
4. **调用 WF-SCENE**：摆放资产、完善碰撞和通行、加入活动与声景，连接上一段。
5. **调用 WF-LIGHT**：试光、最终烘焙、景深与受光检查。
6. **独立 Player 验收**：既走新段，也跨越新旧段边界往返；检查镜头、碰撞、人物活动和光照接缝，通过后提交推送，再推进下一段。

每段精修配合 WF-ITERATE；收到反馈后按 WF-MAINTAIN 更新相关流程，再将修正用于当前段及受影响的相邻段。

**20–30 米是制作与验收单位，不必成为独立场景或加载边界。** 每段都要留下连接下一段的接口，并回归相邻街段。积累的成果应是连续可玩的广东道，而不是彼此孤立的小景。

**给后续 Agent 的启发：**从交付范围选择总流程，以小段完整闭环推进；已有证据和资产可以复用，但新旧段衔接是每批必须关注的集成范围。不能只完成新增模型清单，就把新段标记为完成。

## 如何类推到其他需求

先判断需求主要改变单件资产、运行中的场景、镜头效果，还是新增一段街区；选一个主流程，再按影响调用子流程。明确哪些步骤复用已有证据、哪些必须重新执行。流程选择及验证记录遵循 [WF-MAINTAIN](00-project/workflow-maintenance.md)，不要把示例中的全部子流程机械套到每个小修改上。
