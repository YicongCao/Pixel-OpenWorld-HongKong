# 资产操作指引

本文件由根 [AGENTS.md](../AGENTS.md) 显式引用；修改或生成资产前读取本文件和 [Readme.md](Readme.md)。它是目录操作指南，不另设发布授权。

1. 先查看已有资产、manifest、提示词与 [美术规范](../docs/03-hd2d/art-direction.md)，区分探索概念、生产资产、手工修订和实机证据。旧图中的虚构邻接不能成为场景骨架。
2. 制作街区时先执行 [完整工作流](../workflows/00-project/街区还原工作流.md) 的数据／实景步骤。imagegen 前读取当前技能、实际查看参考图，并传入真实街景及布局引导图；记录输入和输出，不把纯文生图标成现场还原。
3. 提示词明确 HD-2D 日常探索视角、横向主街、纵深巷道、前中远景、建筑重叠、高差依据、光照和可读的行走区；重要繁中／英文招牌独立排字。
4. 按 [HD-2D 生产 SOP](../workflows/10-hd2d/hd2d-production-workflow.md) 先定镜头合同，验证一名角色、一个商铺与一种地面，再批量生成。角色按 [转面与动作流程](../workflows/20-assets/character-production.md) 输出统一锚点的方向／帧数据；纹理、建筑分件、车辆、站口等按用途拆分，概念整图切片不等于可行走资产。
5. 新生成内容放 `generated/`，精修放 `authored/`，清单指定采用版本；重建不得覆盖精修。保留源文件、哈希、来源与许可状态，引用照片规则见完整工作流。
6. 简单几何可直接在 Unity 制作；复杂轮廓、UV 或车辆等按需 Blender。记录米制尺寸、轴向、枢轴与导出设置，检查像素密度、透明深度、受光、脚底锚点和碰撞。
7. 导入成功不等于验收成功。用主角实际走过场景并检查活动和独立 Player；结果写入 `docs/08-blocks/<block_id>/validation/`。仅改文档无需重跑游戏；改资产则验证受影响的导入与画面。
8. 完成后更新目录索引与对应 manifest，按根 AGENTS.md 提交／推送；不得遗漏有效资产，也不提交缓存或不可再分发的参考原件。
